# 🐍 Python Basics – Level 1

This repository contains notes, code examples, exercises, and mini-projects from a beginner-level Python course based on a YouTube tutorial series.

## 📚 Course Overview
This course covers the fundamentals of Python programming, including:

- Variables and Data Types  
- Conditional Statements (if-else)  
- Loops (for, while)  
- Functions  
- Lists, Tuples, Dictionaries  
- Basic Input/Output  
- Simple Projects & Exercises  

Perfect for complete beginners who want to start coding in Python.

## 📁 Structure
